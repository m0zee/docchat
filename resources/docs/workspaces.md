A workspace is one organisation's space in DocChat. Documents, chats, API keys, the widget, chat apps and usage all belong to a workspace, and nothing is shared between workspaces.

## Roles

- **Owners** manage the workspace: members, API keys, AI keys, the widget, chat apps, webhooks and usage.
- **Members** upload documents and chat.

A workspace always needs at least one owner.

## Adding people

Open **Workspace > Members**:

- **Add existing user**: for someone who already has a DocChat account.
- **Send invite link**: DocChat emails a link that works once, for 7 days, and only for that email address.

## Several workspaces

You can belong to more than one workspace. Use the switcher at the top of the sidebar to move between them. Each keeps its own documents and chats.

## Workspace settings

| Page | What it's for |
|---|---|
| General | Name, answer cache, leave the workspace |
| Members | People and invitations |
| API keys | Keys for your own systems ([API guide](/docs/api-guide)) |
| AI keys | Your own free Groq or Gemini key ([guide](/docs/ai-keys)) |
| Widget | The chat bubble for your website ([guide](/docs/widget)) |
| Chat apps | Telegram, WhatsApp and Discord ([guide](/docs/chat-apps)) |
| Webhooks | Get told when documents are ready or fail |
| Usage | Questions, tokens and cache hits per month |
